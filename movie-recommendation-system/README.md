## Özet

Film özetlerinin TF-IDF temsiliyle içerik tabanlı (content-based) benzerlik hesaplanarak film öneren bir sistem. (Not: TMDB veri setleri boyut kısıtı nedeniyle depoya eklenmedi.)

## Kullanılan Teknolojiler

`pandas`, `numpy`, `scikit-learn`, `pillow`
